# Glossário

Os termos que aparecem no prumia, em ordem alfabética. Use quando uma palavra da tela não for óbvia.

| Termo | Significado |
|---|---|
| **A pagar** | Contas do mês ainda não pagas, incluindo as atrasadas. |
| **Administrador / Responsável** | Quem administra a casa: convida pessoas, muda papéis, cria carteiras e categorias. Toda casa tem pelo menos um. |
| **Ajuste de saldo** | A diferença gravada quando você **confere o saldo** de uma carteira com o do banco. Não é receita nem despesa. |
| **Aporte / resgate** | Colocar dinheiro num investimento (aporte) ou tirar dele (resgate). No prumia, é uma transferência. |
| **Arquivar** | Tirar uma carteira ou categoria das listas sem apagar o histórico. Dá para restaurar. |
| **Atrasada** | Conta pendente cujo vencimento já passou. Aparece com o marcador `[ ✖ ]`. |
| **Benefício** | A carteira do vale-refeição/alimentação. O que sobra nela não paga contas da Geral. |
| **Carteira** | Onde o dinheiro fica: Geral, Benefício, Reserva, um investimento... Cada uma tem o seu saldo. |
| **Carteira padrão** | A carteira que recebe receitas e paga contas quando ninguém escolhe outra (normalmente a Geral). |
| **Categoria** | O tipo de gasto (Moradia, Mercado, Saúde...). Pode ter subcategorias e uma carteira sugerida. |
| **Competência** | O mês ao qual uma conta ou receita pertence, mesmo que vença ou caia em outro dia. |
| **Conferir saldo** | Informar quanto há de verdade numa carteira; o app grava a diferença como ajuste. |
| **Conta fixa** | Conta que se repete todo mês (internet, aluguel). O app cria as próximas sozinho. |
| **Convite** | Link para alguém entrar na sua casa. O **convite de cadastro** é outro: serve para a pessoa criar a própria casa. |
| **Dia útil** | Dia de semana que não é feriado nacional. Salários que caem "no 5º dia útil" usam isso. |
| **Essencial** | Marca de categoria que entra no cálculo da reserva de emergência (moradia, mercado, saúde...). |
| **Favorecido** | Quem recebe o pagamento (a empresa de luz, o condomínio). Opcional. |
| **Investimento** | Carteira especial para CDB, Tesouro, poupança. Não paga conta nem recebe receita. |
| **Membro / Participante** | Pode lançar, editar e pagar contas e receitas. |
| **Molde (fonte de receita)** | O "modelo" de uma receita que se repete, como o salário: valor, descontos e regra de data. |
| **Parcela** | Uma das partes de uma compra parcelada. Todas são criadas de uma vez. |
| **Previsto / recebido** | Receita prevista é a que deve entrar; recebida é a que já entrou (a data chegou, ou alguém marcou "caiu"). |
| **Reserva de emergência** | Dinheiro guardado para meses difíceis. A meta é em meses de gasto essencial. |
| **Saldo anterior** | O que sobrou (ou faltou) dos meses passados numa carteira. O saldo continua de um mês para o outro. |
| **Saldo projetado** | O que deve sobrar no fim do mês: previsto para entrar menos o já pago e o que falta pagar. |
| **Só leitura** | Vê tudo, mas não lança nem altera nada. |
| **Transferência** | Mover dinheiro de uma carteira para outra. Não é receita nem despesa. |
