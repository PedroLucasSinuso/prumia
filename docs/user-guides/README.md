# Guias de uso

Passo a passo para quem usa o prumia no dia a dia. Escritos em pt-BR, curtos, **um por tarefa**, pensados para o celular.

| Guia | Status | Ensina a |
|---|---|---|
| [primeiros-passos.md](primeiros-passos.md) | pronto (convites: em breve) | Criar a conta, a casa e convidar quem mora com você |
| cadastrar-e-pagar-contas.md | Fase 1 | Lançar uma conta e marcar como paga em poucos toques |
| parcelas-e-contas-fixas.md | Fase 1 | Registrar compra parcelada e contas que se repetem |
| salario-e-previsao.md | Fase 2 | Lançar salário, descontos e acompanhar a previsão |
| carteiras.md | Fase 2 | Entender saldo livre e saldo de benefício (VR) |
| resumo-do-mes.md | Fase 2 | Ler o resumo e o saldo do mês |
| importar-boleto.md | Fase 3 | Cadastrar conta a partir de PDF ou print |
| instalar-no-celular.md | Fase 4 | Instalar o app (PWA) e acessar pelo Tailscale |

Os guias são criados junto com a funcionalidade (ver o plano de construção, mantido localmente em `docs/product/plan.md`).

## Padrão de cada guia

1. Título com a tarefa ("Como pagar uma conta").
2. Uma frase de contexto: quando usar.
3. Passos numerados, um verbo por passo, citando o nome exato dos botões da tela.
4. "E se..." com os casos comuns (erro, desfazer, permissão de `viewer`).
5. Linguagem simples; sem termos técnicos.
