# Guias de uso

Passo a passo para quem usa o prumia no dia a dia. Escritos em pt-BR, curtos, **um por tarefa**, pensados para o celular.

| Guia | Status | Ensina a |
|---|---|---|
| [primeiros-passos.md](primeiros-passos.md) | pronto | Criar a conta e a casa, entrar e sair |
| [convidar-pessoas.md](convidar-pessoas.md) | pronto (telas: em breve) | Convidar quem mora com você, mudar papéis, sair da casa e redefinir senhas |
| [cadastrar-e-pagar-contas.md](cadastrar-e-pagar-contas.md) | pronto | Lançar uma conta e marcar como paga em poucos toques |
| [parcelas-e-contas-fixas.md](parcelas-e-contas-fixas.md) | pronto (telas: em breve) | Registrar compra parcelada e contas que se repetem |
| [salario-e-previsao.md](salario-e-previsao.md) | pronto | Lançar salário, descontos e acompanhar a previsão |
| [carteiras.md](carteiras.md) | pronto | Entender saldo livre e saldo de benefício (VR) |
| [resumo-do-mes.md](resumo-do-mes.md) | pronto | Ler o resumo e o saldo do mês |
| [importar-boleto.md](importar-boleto.md) | pronto (leitura no servidor: em breve) | Cadastrar conta a partir de PDF, foto ou print |
| [fazer-backup.md](fazer-backup.md) | pronto | Fazer backup, conferir, restaurar e quando fazer |
| [instalar-no-celular.md](instalar-no-celular.md) | pronto (teste em celular: pendente) | Instalar o app (PWA) no Android e no iPhone |

Os guias são criados junto com a funcionalidade (ver o plano de construção, mantido localmente em `docs/product/plan.md`).

## Padrão de cada guia

1. Título com a tarefa ("Como pagar uma conta").
2. Uma frase de contexto: quando usar.
3. Passos numerados, um verbo por passo, citando o nome exato dos botões da tela.
4. "E se..." com os casos comuns (erro, desfazer, permissão de `viewer`).
5. Linguagem simples; sem termos técnicos.
